## Missing or ambiguous assets

- No sunset/city/grid background, board-frame PNG, Perfect Clear sticker, T-Spin or Back-to-Back sticker is present. Their UI stays procedural. Optional background, board-frame and Perfect Clear slots are provided; no fabricated IDs.
- `brick_demon_wave.png` has no matching cosmetic. It is documented/displayed as reference artwork and does not rename Galaxy or create ownership.
- Drop Neon Comet → NeonSparks, Plasma → LightningStrike, Solar → FireBurst; Ghost Spectral → Prism are visual-only mappings in `CosmeticArtwork`. Change the mapping there if desired. Artwork is a marketing icon; actual cosmetic thumbnails and live preview always use the real renderer.
- Reference ranks differ from the actual Rookie/Bronze/Silver/Gold/Platinum/Diamond/Master system. Optional reference ranks default disabled. Configure explicit display mappings only; rewards and progression never change. Existing RankIconConfig IDs take priority.
- Typography uses Roblox’s documented built-in `rbxasset://fonts/families/PressStart2P.json` family throughout. `UIThemeConfig.FontAsset` allows an authorized font-family override. See https://create.roblox.com/docs/reference/engine/datatypes/Font . No uploaded font ID is invented.
- No configured Cash/Energy Developer Products or receipt processor exists. Pack artwork is wired to disabled/unavailable cards. This UI does not create paid rewards; an authorized product/receipt implementation is required before enabling purchases.
