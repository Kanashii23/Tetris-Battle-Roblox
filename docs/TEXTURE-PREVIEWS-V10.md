# Texture and previews v10
Startup marker: 2026-10-11-texture-previews-v10.

Confirmed renderer defect: CosmeticsAssets.get returned an empty URI while a configured texture was loading/failed. Static card cells and frozen/Reduced Motion previews had no load-completion refresh, so a native fallback could persist after loading. Actual Studio image access could not be inspected here; this code defect is separate from accessibility.

Assets.request now returns the central resolved URI independently of presentation readiness. Brick.CosmeticTexture.Image retains that exact URI while loading/failed (or clears it for empty/unmapped cells). The reusable tile resets neutral white, alpha, fit, position and bounds; it displays native fallback until ready. Per-tile IsLoaded and deduplicated load-completion notifications repaint the current saved piece/theme arguments without rebuilding screens, including HOLD/NEXT, board cells, card thumbnails and isolated previews. Notifications match the current URI and cannot replace a switched theme/piece. Destroying removes observers. Failed loads retain the context/URI once-only warning and truthful fallback; no ID is changed or called invalid by a local checker.

All Bricks/Ghost/Drop cosmetic cards now use the existing small 80x40 T-piece thumbnail renderer and retain name/rarity/ownership/actions. CosmeticArtwork promotional thumbnails are no longer constructed on those categories. Sound pack/currency/product/navigation art remains. Shop and Inventory share the path. Unmapped themes remain their own native fallback, not Default art mislabeled as another theme. All asset/config/source PNG mappings remain untouched.

Selected preview keeps the same category-aware engine/loadout, piece/rotate/replay controls and gameplay BrickRenderer/CosmeticRenderer. Drop sprites retain configured URIs while loading, recheck readiness during their bounded lifetime and preserve WhiteBase/six Droplets/Ripple timings. A dedicated transparent, noninteractive DropFXForeground root sits at board ZIndex+12, above the cell roots and textures; sprites sit above it. It tracks board layer changes and is recycled/removed with the existing effect pool. Existing board clipping, gameplay timing and bounds are preserved.
